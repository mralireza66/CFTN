# CFTN Runner · Strasbourg 🏃

Un petit jeu d'arcade pour faire découvrir le **Master Conception, Formation, Technologie & Numérique** (CFTN) de l'Université de Strasbourg sur LinkedIn.

## 🎮 Comment jouer

- **↑** ou **Espace** : sauter (double-saut autorisé)
- **↓** : se baisser (pour passer sous les pièges qui volent)
- **Clic sur le terrain** : sauter
- **Attrapez** les concepts du master (Scénarisation, e-Learning, PIC, Mémoire, Leadership, etc.)
- **Évitez** les pièges du quotidien étudiant (Procrastination, Plagiat, Isolement, etc.)
- 3 vies, le score augmente avec le temps et les bonus

## 🚀 Déploiement sur GitHub Pages (gratuit, 2 minutes)

### Étape 1 : créer un repository
1. Allez sur [github.com/new](https://github.com/new)
2. Nom du repo : `cftn-runner` (ou ce que vous voulez)
3. Cochez "Public"
4. Cliquez sur "Create repository"

### Étape 2 : uploader le fichier
1. Cliquez sur "uploading an existing file"
2. Glissez-déposez `index.html`
3. Cliquez sur "Commit changes"

### Étape 3 : activer GitHub Pages
1. Allez dans **Settings** → **Pages** (menu de gauche)
2. Dans "Source", sélectionnez la branche **`main`** (ou `master`) et le dossier **`/ (root)`**
3. Cliquez sur **Save**
4. Attendez ~1 minute, et votre jeu sera disponible à :
   `https://VOTRE-USERNAME.github.io/cftn-runner/`

### Étape 4 : partager sur LinkedIn
1. Faites une vidéo de l'écran pendant que vous jouez (30 secondes suffisent)
2. Postez la vidéo sur LinkedIn avec un texte du genre :

>
